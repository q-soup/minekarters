FREE 8-DIRECTION HERO - ADVENTURER  v1.2  (+ taster frames from Mini Heroes)
RetroLabStudioCo - https://furkan90x.itch.io

One hand-coded 32x32 pixel-art adventurer that moves in all 8 directions: messy
brown hair, red scarf, blue tunic, a big backpack with a bedroll and a short spear.
Every pixel is generated by a deterministic Python script (Pillow + numpy) from
geometric parts - no generative AI, no traced or downloaded art.

This hero was drawn from scratch for this free pack.  It is NOT one of the eight
heroes of the paid 8-Direction Mini Heroes pack, and none of the adventurer's
frames appear in any paid pack.  (The taster/ folder is the exception: a few
unmodified Mini Heroes frames - see NEW IN v1.2 below.)  It uses the same 32x32
frame size, palette, directions, animation list and file naming, so it sits
next to those heroes without changes.

CONTENTS
  Hero       : 1 (adventurer, default colours)
  Directions : 8 (S, SE, E, NE, N, NW, W, SW)
  Animations : 7 per direction (idle, walk, attack, dash, parry, hurt, death)
  Frames per direction : 35
  Frames total         : 280
  Frame size : 32x32 px, RGBA PNG, fully opaque or fully transparent pixels

ANIMATIONS (per direction)
  name    frames   suggested timing
  idle     4 frames   150 ms per frame (6.7 fps)
  walk     8 frames   100 ms per frame (10.0 fps)
  attack   6 frames    80 ms per frame (12.5 fps)
  dash     4 frames    70 ms per frame (14.3 fps)
  parry    4 frames    90 ms per frame (11.1 fps)
  hurt     3 frames    90 ms per frame (11.1 fps)
  death    6 frames   120 ms per frame (8.3 fps)
  Total   35 frames per direction (35 x 8 directions = 280 frames)
  Hold the last death frame.
  attack = spear thrust (wind-up, lunge, glint at full reach, recover)
  dash   = low sprint dash with speed lines and dust
  parry  = spear raised as a guard, impact spark

FILES
  frames/adventurer/default/   280 single frames
  sheets/                      56 horizontal strips (one per animation and direction)
  atlases/adventurer_default.png   one atlas, 8 columns x 56 rows of 32x32 cells

NAMING
  frames/adventurer/default/adventurer_default_<anim>_<dir>_<nn>.png
  sheets/adventurer_default_<anim>_<dir>.png
      One row, frames left to right, each frame 32x32 (strip width = frames x 32).
  atlases/adventurer_default.png
      Row = animation x direction in the order: idle, walk, attack, dash, parry,
      hurt, death x s, se, e, ne, n, nw, w, sw.  Unused cells are empty.
  Directions: s = down (toward the camera), n = up, e = right, w = left, and the
  four diagonals.  W / NW / SW are mirrored from E / NE / SE (so the spear is in
  the left hand when facing west).

NEW IN v1.1 - A PLAYABLE MINI SET
  The hero files above are unchanged (same names, same pixels).  Added:

  ENEMY: SLIME SCOUT
  A teal jelly slime with a leaf sprout, drawn from scratch with the same code,
  palette, outline and light direction as the adventurer.
  Directions : 8 (S, SE, E, NE, N, NW, W, SW; W / NW / SW mirrored)
  Animations : the same 7 as the hero, same frame counts and timing
               idle 4, walk 8 (hop), attack 6 (body slam), dash 4 (slide),
               parry 4 (harden + spark), hurt 3 (white flash), death 6 (melts)
  Frames     : 35 per direction, 280 in total, 32x32 RGBA
  Files      : frames/slime_scout/default/slime_scout_default_<anim>_<dir>_<nn>.png
               sheets/slime_scout_default_<anim>_<dir>.png   (56 strips)
               atlases/slime_scout_default.png  (8 columns x 56 rows, same row
               order as the hero atlas)
  source/slime_scout_default.aseprite : editable Aseprite file (one tag per
               animation_direction, e.g. "attack_e", with frame timings).
  The slime sits on the same ground line as the hero (bottom row y = 30), so
  both can share one origin point.

  EFFECT: HIT SPARK
  A warm 7-frame impact spark for the spear hit (any direction).
  Files      : frames/fx/fx_hit_spark_00..06.png, sheets/fx_hit_spark.png
  Size       : 32x32 per frame, play once at 50 ms per frame; centre pixel (15,15)
               on the spear tip at the hit frame (attack frame 3).

  DATA (JSON)
  data/adventurer_default.json, data/slime_scout_default.json,
  data/fx_hit_spark.json: frame size, frame counts, ms per frame, loop flag and
  the atlas row of every animation x direction.

  (no smoothing) so the pixels stay sharp.
